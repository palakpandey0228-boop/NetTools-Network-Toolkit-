# NetTools – Network Toolkit

A beginner-friendly networking project made with **HTML, CSS and JavaScript**.

## Features
- IPv4 calculator
- Subnet / CIDR calculator
- Network address
- Broadcast address
- First and last usable host
- Total and usable host count
- IP class detector
- Binary ↔ Decimal converter
- Responsive networking dashboard UI

## How to run
1. Extract the ZIP.
2. Open `index.html` in any modern browser.
3. No server or installation is required.
